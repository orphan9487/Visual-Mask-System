# 聊天情緒標註準則（7 類）

適用於真實聊天測試集與 PTT 論壇子集。兩位標註者照同一份準則各自獨立標註，標完再裁決分歧。

## 一、基本原則

1. 標的是**說話者說這句話當下**的情緒，不是讀者的感受，也不是句中被提到的人的情緒。
2. **只看前文和這一句**，不看後面的發展，也不要猜模型會怎麼判。
3. 每句只選**一個主要情緒**。
4. 判斷要能**指出線索**：用詞、語氣詞、標點、emoji，或這句和前文的關係。指得出線索就標該情緒，即使很淡；指不出來就標中性，不要為了「有情緒」硬標。

## 二、7 類定義

| 標籤 | 定義 | 例句 |
|---|---|---|
| 中性 | 陳述、詢問、回應、打招呼，找不到情緒線索 | 「我明天早上有課」「你幾點到？」「好喔」 |
| 開心 | 高興、興奮、感謝、得意、滿意 | 「終於上榜了！！」「謝啦你最好了」 |
| 悲傷 | 難過、失落、沮喪、遺憾、委屈、無力 | 「我真的好累喔」「又沒抽到…」 |
| 憤怒 | 生氣、不爽、指責、煩躁、抱怨對方 | 「你到底有沒有在聽」「又遲到，每次都這樣」 |
| 驚訝 | 意外、震驚、難以置信，正負皆可 | 「蛤？真的假的」「不會吧」 |
| 恐懼 | 害怕、擔心、焦慮、緊張 | 「明天要報告我好怕」「他會不會生氣啊」 |
| 厭惡 | 嫌棄、鄙視、噁心、不屑 | 「這什麼爛設計」「噁，好油」 |

## 三、容易混淆的情況

| 情況 | 怎麼標 |
|---|---|
| 反話、酸言酸語 | 標**真正的情緒**，再勾「反話／反諷」。例：檔案被刪後說「真好啊，我做了三天」→ 憤怒，勾反諷 |
| 憤怒 vs 厭惡 | 不滿的是**對方的行為**、希望對方改 → 憤怒；嫌棄的是**人或事物本身**、看不起 → 厭惡 |
| 悲傷 vs 恐懼 | 壞事**已經發生** → 悲傷；**還沒發生**、擔心會發生 → 恐懼 |
| 悲傷 vs 憤怒 | 怪別人 → 憤怒；怪自己或感到無力 → 悲傷 |
| 驚訝 vs 其他 | 只有「意外」、看不出好壞 → 驚訝；意外而且明顯開心或生氣 → 標後者 |
| 好友互嗆、開玩笑 | 帶笑、有 emoji 或明顯是玩笑 → 開心；真的不爽 → 憤怒 |
| 「哈哈」「XD」 | 只是緩和語氣、沒有好笑的事時，不單獨構成開心，看整句的意思 |
| emoji 和文字不一致 | 依前文判斷真正的情緒；被拒絕後回「好喔😊」可能是反話 |
| 問句 | 單純詢問 → 中性；質問（「你是不是故意的？」）→ 憤怒 |
| 轉述別人的情緒 | 標說話者自己的情緒；只是轉述（「他很生氣」）→ 中性 |
| 太短、不完整、看不懂 | 選最可能的一個，勾「不太確定」 |
| PTT 推文 | 標推文作者的情緒；標題與內文只當語境；推、噓符號已移除，不要猜 |

## 四、兩個勾選框

- **反話／反諷**：字面意思和真正意思相反，或明顯誇張諷刺時才勾。單純抱怨不算反諷。
- **不太確定**：兩種標籤都說得通時才勾，仍要選一個主要的。不要用來跳過題目。

## 五、流程

1. 讀完本準則與標註頁上的說明。
2. **試標**：抽約 30 則各自標完，算一致度。
   - `python -m src.annotation.chat_testset sample --items data/chat_testset/forum_items.jsonl --n 30 --out data/chat_testset/pilot_items.jsonl`
   - `python -m src.annotation.chat_testset agree data/chat_testset/pilot_labels_*.json --items data/chat_testset/pilot_items.jsonl --adjudicate data/chat_testset/pilot_adjudicate.jsonl`
   - κ 低於 0.4 時，兩人討論分歧題，把新的判斷規則補進第三節，再開始正式標註。
3. **正式標註**：各自獨立完成，期間不討論。每次連續標註不超過 1 小時。
4. **匯出檔名**：網頁會依載入的題目檔自動命名：真實聊天 `labels_<名字>.json`，PTT `forum_labels_<名字>.json`，試標 `pilot_labels_<名字>.json`。不要自行改名。
5. **裁決**：`agree` 產生分歧清單，兩人（或第三位）依本準則討論後填入 `final`。裁決時同樣不看模型答案。

## 六、隱私

- 語料只在本機處理，不外傳、不截圖分享。
- 標註過程中發現未遮蔽的個資（姓名、電話、地址等），記下題號，告知負責人處理。
