# 穩定部署指南

**問題**：免費 Cloudflare quick tunnel 每次重啟都換一組隨機網址，導致要手動更新 `.env` 與 LINE Console 的 webhook URL——demo 當天最容易在這裡出包。

以下兩個方案，依你要的穩定程度選。

---

## 方案 A（推薦，立即可用）：一鍵啟動器，自動同步

不需任何額外帳號或網域。用既有的免費 tunnel，但**全程自動化**——`scripts/launch.py` 會自動抓新網址、更新 `.env`、並用 LINE API **自動設定 webhook**，你完全不用手動同步。

```bash
.venv\Scripts\python scripts\launch.py
```

它會依序：
1. 啟動 Cloudflare tunnel、擷取新網址
2. 寫入 `.env` 的 `PUBLIC_BASE_URL`
3. 啟動伺服器（等 `/health` 就緒）
4. **用 LINE API 自動設定 webhook endpoint**（`PUT /v2/bot/channel/webhook/endpoint`）
5. 印出 webhook 網址，按 Ctrl+C 一鍵關閉全部

**前置**：`.env` 已填好 `LINE_CHANNEL_SECRET` / `LINE_CHANNEL_ACCESS_TOKEN`；`cloudflared` 已安裝。

> 這解決了「手動同步」的痛點，但網址**仍會在每次重啟時改變**（只是改了也自動同步）。若要網址**永遠不變**（例如 demo 中途 tunnel 斷線也不怕），用方案 B。

---

## 方案 B（最穩）：固定網域，網址永不變

### B-1. ngrok 免費靜態網域（最簡單，不需買網域）★ 建議

ngrok 免費方案現在提供**每帳號一個免費靜態網域**，這是最省事的固定網址方案。

1. 註冊 [ngrok](https://ngrok.com/)（免費），到 dashboard 複製 authtoken
2. 安裝並設定：
   ```bash
   winget install ngrok.ngrok
   ngrok config add-authtoken <你的authtoken>
   ```
3. 到 dashboard 的 **Domains** 領取免費靜態網域（形如 `your-name.ngrok-free.app`）
4. 啟動（網址固定）：
   ```bash
   ngrok http --url=your-name.ngrok-free.app 8000
   ```
5. 在 LINE Console 把 webhook 設為 `https://your-name.ngrok-free.app/webhook`——**設定一次，永不再改**
6. 之後啟動只要：先跑 ngrok，再 `.venv\Scripts\python -m uvicorn src.line_bot.app:app --port 8000`

> 用固定網域時，`.env` 的 `PUBLIC_BASE_URL` 直接填那個固定網址即可，不必用 launch.py 的自動同步。

### B-2. Cloudflare Named Tunnel（若你已有網域）

適合已有網域掛在 Cloudflare 的情況，可得 `mask.yourdomain.com` 這種永久網址。

```bash
cloudflared tunnel login                              # 瀏覽器授權
cloudflared tunnel create vms                         # 建立具名 tunnel
cloudflared tunnel route dns vms mask.yourdomain.com  # 綁定子網域
```
建立 `config.yml`：
```yaml
tunnel: vms
credentials-file: C:\Users\<你>\.cloudflared\<tunnel-id>.json
ingress:
  - hostname: mask.yourdomain.com
    service: http://localhost:8000
  - service: http_status:404
```
啟動：
```bash
cloudflared tunnel run vms
```
LINE webhook 設為 `https://mask.yourdomain.com/webhook`，永不改變。

## Demo 當天建議

| 情境 | 用哪個 |
|---|---|
| 想最省事、可接受網址每次變（但自動同步） | 方案 A（launch.py） |
| Demo 要穩、網址不能變、怕中途斷線 | 方案 B-1（ngrok 靜態網域，免費不需網域） |
| 你已有網域 | 方案 B-2 |

**無論哪種**，demo 前務必：
- [ ] `.env` 設 `VMS_MODEL=breeze2-3b`（反諷判讀最佳）
- [ ] 先暖機一則訊息（首次載入模型 1–2 分鐘）
- [ ] `python -m src.line_bot.preflight` 全綠
- [ ] 準備錄影備援（見 `docs/demo_腳本.md`）

## 安全提醒

- `scripts/launch.py` 會讀 `.env` 裡的 access token 去呼叫 LINE API 設定 webhook——**token 只在你本機使用、不外傳**。
- 正式 demo 建議把 `/debug/*` 端點關閉或加保護（目前無認證，任何人知道網址就能呼叫你的模型）。
