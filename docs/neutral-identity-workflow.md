# 中性身分基底流程

聊天室列表的 LoRA 面具基底上傳提供三種模式：

- auto：有已確認中性基底時，比對新照片與該基底身分；通過後預覽沿用的基底。輸出不是新照片的還原，不保留新照片姿態／背景。
- natural：使用者提供自然中性照片；不改表情。
- new_identity：明確忽略舊基底，嘗試自動中性化新照片；確認前保留舊基底。

首次 auto 與 new_identity 使用現有 LivePortrait absolute-exp 中性化。這不是新模型或大小眼修復；已知可能存在眼形／嘴形失真。
中性化輸出與原照、或新照片與既有基底，使用 InsightFace buffalo_l cosine 初步篩檢；0.30 是暫定工程門檻，未校準為安全身分驗證，也不是成功率。
單人臉偵測與 cosine 無法證明表情中性、五官對稱或眼鏡無失真；必須由使用者驗收，不合格需補照片。
目前一次一張上傳，不含多張參考融合模型；不能保證哭臉、鬼臉、閉眼或遮擋輸入都可還原。

上傳只保存 pending_base，確認後才記錄 neutral_identity_reference 及 selected_base。
neutral 訊息仍直接使用已確認照片，其餘情緒沿用既有後端；未修改全域生成模式。
六項模擬單元測試通過，未進行真實身分辨識門檻校準或完整瀏覽器驗收。
