# 推理層 ⇄ 生成層　介面合約（VisualInstruction v1.1）

本文件定義兩人分工的邊界：**推理層**（輸入感知／推理／學習迴圈）產出一份
`VisualInstruction`，**生成層**（AnimateDiff + SD1.5 + LoRA）消費它。
雙方只需遵守此 schema，即可各自獨立開發與測試。

## 資料流

```
LINE/前端訊息
   │        ← 推理層（你負責）
   ├─ Contextual Buffer（取對話語境）
   ├─ ERC Engine（情緒判讀，Affective Analyzer）
   └─ Visual Instruction Generator（+ Modality Selector + Identity-DB）
   │
   ▼  VisualInstruction (JSON)   ← 這就是合約
   │        ← 生成層（隊友負責）
   ├─ 依 identity.lora_path 載入 LoRA、set weight = identity.lora_weight
   ├─ 依 modality 決定產影片或靜態圖
   ├─ 用 positive_prompt / negative_prompt / generation_hints 生成
   └─ 產出影片(mp4/gif) 或 貼圖(png)
```

## VisualInstruction 欄位

| 欄位 | 型別 | 說明 | 生成層如何使用 |
|---|---|---|---|
| `schema_version` | str | 合約版本（目前 "1.0"） | 檢查相容性 |
| `user_id` | str? | 使用者識別 | 記錄用 |
| `identity.mask_id` | str | 面具識別碼 | — |
| `identity.trigger` | str | LoRA 觸發詞 | 已含在 positive_prompt |
| `identity.lora_path` | str | LoRA 權重相對路徑 | **載入此 LoRA** |
| `identity.lora_weight` | float | 融合權重 | **set_adapters 權重** |
| `identity.base_prompt` | str | 身分基底描述 | 已含在 positive_prompt |
| `emotion` / `emotion_zh` | str | 情緒（7 類） | 命名輸出檔用 |
| `intensity` | float 0-1 | 情緒喚醒度 | 可調表情強度 |
| `modality` | "video"｜"sticker" | 輸出型態 | **決定產影片或靜圖** |
| `scene_description` | str | 英文場景描述 | 人類可讀說明（可作備援 prompt） |
| `positive_prompt` | str | 完整正向 prompt | **直接餵給 pipeline** |
| `negative_prompt` | str | 負向 prompt | **直接餵給 pipeline** |
| `generation_hints` | dict | num_frames / steps / guidance_scale / lora_weight | **生成參數** |
| `source.utterance` | str | 原始訊息 | 除錯 |
| `source.rationale` | str | 推理鏈 | 除錯 |
| `intent` | dict? | **(v1.1 選用)** 語意意圖分析：intent/emotion_cause/target/sincerity | 生成層可忽略；回饋策略可用（如 sarcastic→調整表情） |

## 生成層最小消費範例

```python
import json
from diffusers import AnimateDiffPipeline  # 生成層既有

def generate_from_instruction(vi: dict, pipe):
    # 1. 載入該使用者的面具
    lora = vi["identity"]
    pipe.unload_lora_weights()
    pipe.load_lora_weights(<dir(lora["lora_path"])>, weight_name=<name>,
                           adapter_name=lora["mask_id"])
    pipe.set_adapters([lora["mask_id"]], adapter_weights=[lora["lora_weight"]])

    # 2. 依 modality 決定影格數
    h = vi["generation_hints"]
    out = pipe(prompt=vi["positive_prompt"],
               negative_prompt=vi["negative_prompt"],
               num_frames=h["num_frames"],
               num_inference_steps=h["num_inference_steps"],
               guidance_scale=h["guidance_scale"])

    # 3. 依 modality 輸出
    if vi["modality"] == "video":
        return export_video(out.frames[0])   # mp4/gif
    return out.frames[0][0]                   # 靜態貼圖 png
```

## 推理層如何產出（你負責，已實作）

```python
from src.services.emotion_service import produce_visual_instruction  # async
out = await produce_visual_instruction("氣死我了", history, user_id="Uxxx")
vi = out["instruction"]   # ← 交給生成層
```

呼叫端可直接取得 `out["instruction"]`，再交給生成層處理。

## 產出模組（推理層側）

- `src/reasoning/identity_db.py` — Identity-DB（面具註冊、user→面具綁定，持久化 data/identity_db.json）
- `src/reasoning/visual_instruction.py` — VisualInstructionGenerator + ModalitySelector + schema
- 情緒→表情/喚醒度對照表在 `visual_instruction.py` 的 `EMOTION_PROFILE`

## 變更規則

schema 欄位為公開合約，**任一方要改欄位須雙方同步並升 `schema_version`**。
情緒表情描述（EMOTION_PROFILE）、面具設定（Identity-DB）屬推理層內部，可自由調整。
